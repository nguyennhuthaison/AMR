Đây là toàn bộ code cho vi điều khiển STM32 trong một xe tự hành, bao gồm các thành phần sau:

1. Giao tiếp với máy tính nhúng qua giao thức UART.
2. Tính toán odometry bao gồm các thông tin về vị trí, góc xoay, vận tốc của xe.
3. Thuật toán PID để điều khiển chính xác vận tốc động cơ.
4. Điều khiển động cơ bằng phương pháp điều chế độ rộng xung PWM.

This is the complete code for the STM32 microcontroller in an autonomous vehicle, featuring the following components:
1. Communication with the companion computer via the UART protocol.
2. Odometry calculation including position, orientation, and velocity of the vehicle.
3. PID algorithm for precise motor speed control.
4. 4. Motor control using Pulse Width Modulation (PWM).
